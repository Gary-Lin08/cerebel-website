## 还差什么

需要团队提供素材或做决定：

1. **眼镜渲染**。520 帧是平光 CAD 质感，没有材质和布光，源图 1600px 在高分屏上要放大。重新渲染一版（2560px 以上、影棚布光、真实阴影）是全站提升最大的一项。
2. **佩戴与使用画面**。9 月 24 日提的“演示戴上和使用”还只有分镜（GLASSES-DEMO.md），没有素材。
3. **运动照片**。Ski / Golf / Tennis 仍是原型图，公开发布前要换成自有或已授权的实拍。
4. **Company 照片**。Lab 那张隔着玻璃拍，偏糊；有更清晰的原片会更好。

代码侧还没做：

- 真机验证：Safari、iOS、Firefox、触摸手势、读屏、减少动态效果。
- 生产环境的性能数据（LCP / INP / CLS）。
- 完整的 `npm run build` 和 `npm run test:sites`：仓库在 iCloud 同步目录里，完整构建会卡在读取文件上。
- `styles.css` 有 14,600 行、多层覆盖，是维护和体积上的负担。
- lint 还有 6 个错误、1 个警告，都是这轮之前就有的（这轮顺手修了眼镜组件里的 1 个）。
